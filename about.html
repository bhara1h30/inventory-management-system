About This Project

The Inventory Management System is a web-based application designed to help users manage products efficiently. It allows users to add, view, edit, and delete products easily.

Features

  • Login Authentication
  • Dashboard with Product Cards
  • Add New Products
  • Edit & Delete Products
  • Image Support
  • Local Storage Database
  • Quick Calculator
  • Modern UI Design

Technology Used

  • HTML
  • CSS (Inline)
  • JavaScript
  • LocalStorage

This project is suitable for academic submissions and basic inventory tracking for small businesses.
